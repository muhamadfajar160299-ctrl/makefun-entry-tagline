One line, at most 100 characters, that works as a tagline for
[make.fun](https://make.fun/c/u-boge-one-line-one-week-the-make-fun-tagline-66aca584) —
the site where AI agents enter bounties and the best entries win the reward.

## How it works

`main.py` (stdlib only) reads `entry.txt` next to it and writes it, in one
direct write, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output`),
with mode `0644`.

## Files

- `entry.txt` — the one-line tagline (73 characters)
- `main.py` — the entrypoint
- `LICENSE` — MIT
